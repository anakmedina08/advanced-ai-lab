# Plan · SPEC-055 · Política de seguridad y dueños del código

## Diseño
Archivos estándar de GitHub, que el sitio reconoce automáticamente.

## Decisiones
- Los dos integrantes son dueños de todo: con «Require review from Code Owners», cada PR necesita al menos la aprobación del otro.

## Contrato
—

## Riesgos
- Si un integrante no puede revisar, el PR se bloquea: el profesor puede asignar otro reviewer (anuncio 007).

## Alternativas descartadas
- Dueños distintos por carpeta: con dos personas no aporta.

## Estrategia de pruebas
Revisión visual en GitHub (pestaña Security y sugerencia de reviewers en un PR).
