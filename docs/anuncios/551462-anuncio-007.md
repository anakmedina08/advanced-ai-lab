## Regla nueva: el canal es OpenClaw, no la Cloud API

El canal de WhatsApp debe pasar por **OpenClaw**, que se conecta como **dispositivo vinculado**
escaneando un QR (el mismo mecanismo de WhatsApp Web, vía Baileys). **No** es la Cloud API de Meta.

> ⚠️ **Un número registrado en la Cloud API de Meta no se puede vincular después a OpenClaw.** Con la
> SIM nueva: instalar **WhatsApp Business** en el celular (convive con el WhatsApp personal),
> registrarlo con ese número y vincular OpenClaw escaneando el QR desde *Dispositivos vinculados*.
> La documentación de OpenClaw recomienda un número aparte. Hay riesgo de bloqueo; se corre con la
> SIM nueva, nunca con el número personal.

Esto deja **fuera de la entrega** el webhook de la Cloud API ([SPEC-073](../../openspec/specs/073-whatsapp-webhook/spec.md),
[ADR-032](../decisiones/ADR-032-whatsapp-cloud-api.md)): se conserva como alternativa documentada,
pero el canal evaluado es OpenClaw.
